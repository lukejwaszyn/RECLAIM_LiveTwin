current operating instructions.

`deployment/CURRENT_CONVENE_ROUTED_SYSTEM_HANDOFF.md`: Windows 10 owns live cRIO
acquisition, the MacBook owns scenarios, and Convene routes source data to the
cloud engine and computed state back to Convene.
