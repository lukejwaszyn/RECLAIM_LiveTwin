# Retired MacBook direct Convene pairing

The MacBook scenario gateway now writes one owner-private local JSON file for
Convene File Watch. The former direct `/machine/publish` pairing utility and its
tests are preserved here only as history because running that utility would
re-enable a duplicate source writer.

Use `pi_gateway/macos/configure_scenario_host.py` and
`pi_gateway/macos/README.md` for the current setup.
